# Early Alzheimer's Prediction System

Machine learning project for early Alzheimer's prediction using Python.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Models Used
- Logistic Regression
- Random Forest
- Gradient Boosting

## Results
Achieved 93.3% accuracy with Gradient Boosting and ROC AUC of 0.97.
